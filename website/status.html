What these checks cover

The API runs a bounded database query and, when Redis is the active rate-limit store, a Redis ping. Disabled Redis is expected in the PostgreSQL-backed beta mode. A failed active dependency produces a degraded result.

Checks refresh every 30 seconds while this page is visible. Results older than 60 seconds become unknown. Login, audit submission, billing, email delivery, and webhook delivery are not exercised here. No historical uptime percentage is calculated.

Incident updates & support

See public GitHub issues for maintainer-published updates, or contact support@agentaudit.online. Include the time and request ID, but never credentials or customer data.

The copy at agentaudit.online shares the API's hosting and may be unavailable during an outage. Use the independently hosted GitHub Pages copy instead. GitHub issues remain the fallback for maintainer-published updates.
